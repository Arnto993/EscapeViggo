# Escape Viggo — Canonical Art References

These images are approved visual references for M22.

## Authority

The reference images define:
- character silhouette
- proportions
- clothing
- colour language
- facial character
- prop shape language
- overall visual identity

`CHARACTER_ART_SPECS.md` and `ART_DIRECTION_PROPS.md` remain authoritative
for technical production rules.

IMPORTANT:
Final game assets must use the project's stylized low-poly aesthetic.
Reference images may contain smoother rendering than the intended meshes.
Do not interpret smooth concept-art surfaces as a requirement for dense geometry
or photorealistic materials.
